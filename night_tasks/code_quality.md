## Objective: Improve maintainability and readability
**Investigation:** Scan the codebase for code smells: overly long functions, deeply nested conditionals, duplicated logic, and inconsistent naming conventions.
**Action:** Refactor the code to be cleaner and more modular. Extract reusable utilities. Ensure the refactoring does not change the external behavior of the application. Leave the codebase in a state where a new developer could understand it easily.
